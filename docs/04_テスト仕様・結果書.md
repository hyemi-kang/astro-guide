## 4. 非機能テスト

| No. | 項目 | 結果 |
| --- | --- | --- |
| N-01 | フレームレート（公園モード、夜、headless Edge、3 秒計測） | 約 60 fps（デスクトップ幅、スマホ幅とも）。**実機・低性能 PC では未測定** |

| N-03 | スマホ幅（390×844）の空画面：下部の操作バー | 初回は横にはみ出して切れた。**折り返す形に修正して再確認**し、はみ出しなし。ただし縦に 3 段積みになりキャラクターを一部覆う |
| N-04 | スマホ幅の船内画面：モニター | 初回はモニターが画面外に切れた。縦長用の配置に修正し、モニターが枠内に収まることをスクリーンショットで確認（縦長では小窓の地図は非表示。Begin 後は全画面の地図） |
| N-05 | サブパス配信（`/little-sky/`）でのビルド成果物 | 地図 241 か国を描画し、404 なし。合格 |

## 5. 検証で見つけて修正した不具合

| 内容 | 原因 | 対応 |
| --- | --- | --- |
| 星座カードの写真が真っ黒 | Wikipedia の先頭画像が「透明背景の黒線の IAU 図」で、暗い背景に溶けた。そもそも実写ではなかった | 画像の背景を明るくし、メディア一覧から実写（JPEG）を優先して取得 |
| 太陽を隠した円盤が太陽と見分けにくい | 円盤が白く太陽と同じ見た目 | 紙の色・縁取り・影を付与 |
| 空が暗くなっても円盤・ヒーローが残り星座が見にくい | 演出を消す処理がなかった | 夜になったあとフェードアウト。戻す際は再表示してから外す |
| 夜に地面が見えず「宇宙にいるよう」 | 地面の色が夜空とほぼ同じ | 夜の地面と地平線のぼかしを明るく調整 |
| 時刻バーに「Now」が二重表示 | ラベルとボタンが重複 | 現在時は「Live」、ずれているときは差分と「Now」 |
| GSAP の警告「Invalid property radius」 | 未対応のプロパティ名を指定 | `borderRadius` に修正 |
| ファビコンの 404 | 指定ファイルがなかった | SVG を追加（相対パス） |
| スマホ幅の操作バーのはみ出し | 折り返し未設定 | 折り返し・間隔を調整 |
