## 1. 座標・投影（`src/astro`）

### 1.1 `coords.ts`

| 関数 | 仕様 |
| --- | --- |
| `radecToVec(ra°, dec°)` | 赤経・赤緯 → EQJ 単位ベクトル |
| `eqjToHorizon(date, place)` | `Astronomy.Rotation_EQJ_HOR` の行列を行優先 3×3 に転置して返す（`out_j = Σ r[i][j]·v_i` の仕様に合わせる） |
| `toAltAz(h)` | 地平ベクトル（x=北, y=西, z=天頂）→ 高度・方位（方位は北=0°、東=90°：`atan2(-y, x)`） |
| `altitudeOf(m, eqj)` | 行列の第 3 行で高度のみを高速に算出 |

### 1.2 `projection.ts`（立体射影）

- カメラは `yaw`・`pitch`・`fov`（縦の視野角）。地平座標では `yaw = −方位`、赤道座標では `yaw = 赤経`。
- 画面右方向 `right = (sin yaw, −cos yaw, 0)`、`up = right × d`。空が鏡像にならないよう「右 = yaw が減る向き」に統一。
- 縮尺 `scale = (H/2) / (2·tan(fov/4))`。投影は `k = 2/(1+cos c)`、`x = cx + k·(v·right)·scale`。
- 逆投影 `unproject` は `c = (4−r²)/(4+r²)`、`k = 4/(4+r²)` から単位ベクトルを復元。地面・天の川の描画で使用。往復一致を確認済み。

### 1.3 `bodies.ts`

9 天体（太陽、月、水星〜海王星）について、観測地点基準の赤経・赤緯（`Equator(..., ofdate=false, aberration=true)`）、等級・位相・太陽距離（`Illumination`）、距離、視直径（実半径と距離から）、太陽との離角を返す。月相は `MoonPhase`。

### 1.4 `visibility.ts`

| 関数 | 仕様 |
| --- | --- |
| `computeVisibility(eqj, place, now, extent)` | 現在の高度・方位、24 時間内の出没（高度 0° の跨ぎ）、最大高度と時刻、太陽高度 −12° 未満の暗い時間帯の最大高度、見頃の日付、高度 20° 以上で見える月、全体が見える緯度範囲 |
| `bodyRiseSet(id, from, place)` | `SearchRiseSet`、`SearchHourAngle` による厳密な出没・南中 |
| 全体が見える緯度範囲 | `[decMax − 90°, 90° + decMin]`（星座線の最小・最大赤緯） |
| キャッシュ | 10 分刻みの行列、年間の月別サンプル、太陽赤経表を保持して再計算を避ける |

### 1.5 `skyColor.ts` / `starColor.ts`

- 太陽高度 −18°〜+25° の 6 段階の配色（天頂色・地平色・限界等級）を線形補間。
- 恒星色：B−V → 温度 → RGB。スペクトル型の目安（O/B/A/F/G/K/M）を温度から推定。

## 2. 描画（`src/sky/renderer.ts`）

毎フレームの処理順：

1. 行列（EQJ→地平、宇宙モードは単位行列）とカメラを更新。天体位置は 1 秒単位でキャッシュ。
2. 太陽高度から空の見た目を決定（「太陽を隠す」中は `skyInfo.dark` で夜へ補間）。
3. 空のグラデーション（天頂〜視線方向の地平を結ぶ線形グラデーション）と、太陽のグロー。
4. 低解像度パス（1/4）：画素ごとに逆投影し、(a) 天の川テクスチャを参照、(b) 地平より下を地面として色・透明度を決定（境界はなめらかに補間）。
5. 宇宙モードのみ：赤経・赤緯格子、天の赤道、黄道、天の極のラベル。
6. 境界線、星雲・星団・銀河、星座線（ホバー中は強調と頂点リング）、星座名。
7. 恒星：等級に応じた半径とスプライト（B−V で 12 段階の色）。明るい星に回折スパイク。瞬き（星ごとの位相）、地平線近くの減光と瞬きの増強。
8. 惑星・月（太陽に向く明部の向きと位相）・太陽。
9. 地面（4 の結果を重ねる）、公園モードは木々のシルエット（2 層、疑似乱数固定）、方位ラベル。

### 当たり判定（`hitTest`）

優先順位：天体（太陽・月・惑星）→ 星雲 → 名前付きの恒星（12px 以内）→ 星座線（線分までの距離 13px 以内）。恒星にホバーしたときは、その恒星が属する星座も強調する。

## 3. 操作（`src/sky/SkyCanvas.tsx`）

| 操作 | 仕様 |
| --- | --- |
| ドラッグ | 画面中心付近で 1px ≈ `1/scale` ラジアン。`yaw += dx·k`、`pitch += dy·k`。地平モードの pitch は −12°〜90°、宇宙は −90°〜90°。離したときの速度で慣性（フレームごとに減衰） |
| ホイール／ピンチ | `fov` を指数的に変更。範囲は公園・全天 8°〜125°、宇宙 2°〜140° |
| クリック | 移動量 5px 未満かつ 600ms 以内で選択（`store.select`） |
| リセット | GSAP で既定の視点へ補間（宇宙モードは現在の天頂の赤経・赤緯） |
| 外部制御 | `skyControls`（`panTo`、`resetView`、`zoomBy`）を手帳・HUD・太陽演出から利用 |

## 4. 太陽を隠す（`src/sky/SunBlocker.tsx`）

GSAP タイムライン（`anim = {p, spin, cover, alpha}`）。毎フレーム `gsap.ticker` で太陽の画面座標へ追従する。

| 段階 | 紙（Paper） | ヒーロー（Hero） |
| --- | --- | --- |
| 1 | 太陽が視野外なら太陽へ視点を移動 | 同左 |
| 2 | キャラクターが紙を掲げる姿勢（`actionPose='paper'`） | ヒーローが左から飛来（`p`: 0→1） |
| 3 | 円盤が手元から弧を描いて太陽へ（回転・拡大） | マントを広げて太陽を覆う（`cover`） |
| 4 | `cover` を 1 にし、コロナ状のリングを表示 | 同左 |
| 5 | `skyInfo.dark` を 0→1（空が夜へ） | 同左 |
| 6 | **`alpha` を 1→0 で演出を消す**。キャラクターは見上げる姿勢へ戻る | 同左 |
| 戻す | `p=1, cover=1` にして `alpha` を 1 に戻し（再び太陽を覆う）、`dark` を 0 へ、その後に退場 | 同左 |

太陽が地平線の下（夜）のときはトグルを無効にする。宇宙モードでは非表示。

## 5. 手帳（`src/ui/Notebook.tsx`）

- 検索対象：星座 88、惑星（太陽・月含む）、名前付き恒星、名前付き深宇宙天体。ラベル完全一致 → 前方一致 → 部分一致の順で並べ、種別順で整える（最大 40 件）。
- 開いた時点の日時と地点を固定して表示（「手帳を開いた地点基準」）。
- 一覧（検索なし）：現在の高度が 25° を超える星座上位 10、3° を超える惑星。昼は星が見えない旨を表示。
- 詳細：`VisibilityPanel`（現在の状態、出没、最大高度、暗い時間帯のピーク、見頃、月、緯度範囲）、「Show in the sky」（視点移動）、「Open the full card」。

## 6. 情報モーダル（`src/ui/InfoModal.tsx`）

| 種別 | 内容 |
| --- | --- |
| 星座 | ポラロイド（写真→IAU 図→自作星図。裏面は自作星図）、面積と順位、最輝星、導入者、見える時刻、神話、豆知識、探し方、名前付き星一覧、用語 |
| 恒星 | 色・スペクトル型・温度、距離・種類・年齢・光度（手書きデータがある星のみ）、所属星座、所属銀河、豆知識、見える時刻 |
| 惑星・太陽・月 | 現在の距離・光行時間・等級・視直径・位相・離角、出没、物理量、豆知識 |
| 星雲・銀河 | 種別、等級、距離・大きさ・年齢（ある場合）、解説、見える時刻 |

写真取得（`data/wiki.ts`）：候補タイトルを順に `page/summary` で検索し、曖昧さ回避ページや内容が合わないものを除外。星座はさらに `page/media-list` から JPEG の写真（図・版画・ロゴ等のファイル名パターンを除外）を探す。

## 7. 星図（`src/ui/StarChart.tsx`）

星座の中心を基準にした立体射影のチャート。北が上、東が左（空を見上げたときの向き）。表示は 5.4 等星まで、色は B−V。星座線を重ね、2.6 等より明るい恒星に名前を表示。

## 8. キャラクターと演出

- `Prince.tsx`：SVG の部位ごとに GSAP でポーズ制御（見上げる／歩く（ループ）／手帳／紙を掲げる／着席）。マフラーの揺れ・呼吸は常時。
- `SuperHero.tsx`：飛行ポーズ。マント（円）を拡大して太陽を覆う。
- `ShipScene.tsx`：地図レイヤーをモニターの矩形へ変換して表示し、Begin でモニターへズーム。
- `LandingScene.tsx`：星の流れの減速、雲の通過、機体の降下、着陸。空の終端色は実際の太陽高度から決定。
- 公園のキャラクターは着陸後に画面左から歩いて登場（初回のみ）し、手帳を開くと手帳のポーズになる。

## 9. 既知の制約

- 星表は 6 等星まで。固有運動・視差・光行差の細かな補正は行わない（恒星）。
- 高度は大気差を含めず表示（地平線付近の天体の見え方との差は最大約 0.5°）。
- 惑星の「出没」以外の可視性（見頃など）は星座・恒星・星雲のみ。
- 宇宙モードは地球からの見かけの天球であり、視点の移動（恒星までの距離の違いによる視差）は行わない。
