## 1. 目的・背景

星座・恒星・惑星を「その場所・その時刻に実際に見える姿」で、正確かつ親しみやすく学べる Web サイトを作る。
天文の専門サイトとして通用する正確さ（位置・時刻・データ）を保ちつつ、アニメーションと物語性のある体験（宇宙船 → 公園 → 空）で興味を引く。

## 2. 利用者

| 利用者 | 想定 | 目的 |
| --- | --- | --- |
| 一般の閲覧者 | 星空に興味のある大人・子ども | 今夜どの星座が見えるかを知る、物語や豆知識を楽しむ |
| 天文愛好家 | 観望計画を立てたい人 | 場所・日時を指定して、星座・惑星の位置と出没時刻を確認 |

## 3. スコープ

**対象**：Web ブラウザ（PC を主、スマートフォン幅にも崩れない）で動作する静的 Web アプリ。サーバー・DB・ログインなし。
**対象外**：望遠鏡の制御、観測記録の保存、多言語切替（本版は英語のみ）、ユーザー認証、位置情報（GPS）の自動取得。

## 4. 業務（利用）フロー

1. 宇宙船の中で世界地図を見る → 国を選ぶ → 地域を選ぶ（緯度・経度・タイムゾーンが決まる）
2. 着陸し、公園で空を見上げる（現在時刻・現在地の空）
3. 空をドラッグ／ズームして探す。ホバーで名前、クリックで詳細
4. 手帳で検索し、見える時期・時刻を調べる
5. 昼なら「太陽を隠す」で昼の星座・惑星を確認。宇宙モードで全天を自由に眺める

## 5. 機能要件

| ID | 要件 | 優先度 |
| --- | --- | --- |
| F-01 | 宇宙船内の世界地図で国を選択でき、選択した国へズームする | 必須 |
| F-02 | 国内の地域を一覧から、または地図上の任意地点クリックで選択できる（緯度・経度・タイムゾーンを取得） | 必須 |
| F-03 | 現在時刻・選択地点で見える星・星座・惑星・太陽・月を表示する | 必須 |
| F-04 | 昼間は星が見えない状態を再現し、太陽の位置も表示する | 必須 |
| F-05 | 「太陽を隠す」トグル（紙で隠す／ヒーローが隠す）で昼の星座・惑星を確認できる。隠した後は演出が消えて星座が見やすい | 必須 |
| F-06 | 公園でキャラクターが空を見上げる表現（『星の王子さま』風）。着陸後に歩いて登場する | 必須 |
| F-07 | 星はきらめく（瞬き）表現とする | 必須 |
| F-08 | ホバーで名前を表示し、星座は線で結んで強調する | 必須 |
| F-09 | クリックで詳細モーダル（ポラロイド写真、データ、物語・豆知識）を表示する | 必須 |
| F-10 | 手帳で星座・恒星・惑星・星雲を検索でき、現在地基準で「いつ見えるか」を表示する。開閉時にキャラクターの動作がある | 必須 |
| F-11 | ドラッグで空を移動、ホイール／ピンチで拡大縮小、「元の向きに戻す」ボタン | 必須 |
| F-12 | 時刻を変更（±12 時間、日・月単位のジャンプ）し、「現在」に戻せる | 必須 |
| F-13 | モード切替：公園／全天（全画面の空）／宇宙（キャラクター・地平線なし、自由移動・拡大） | 必須 |
| F-14 | 宇宙モードから「地球の位置へ戻る」「前の地図へ戻る」ができる | 必須 |
| F-15 | 星の情報：色・スペクトル型・種類（赤色巨星等）・距離・年齢・所属銀河・用語解説（赤方偏移等） | 必須 |
| F-16 | 星雲・銀河・星団（アンドロメダ銀河、オリオン大星雲等）を表示し、情報を見られる | 推奨 |
| F-17 | 天の川を空の背景として表示する | 推奨 |
| F-18 | 星座境界線・星座名の表示切替 | 推奨 |
| F-19 | 星座・惑星に関する面白い話（神話・豆知識）を読める | 必須 |

## 6. 非機能要件

| ID | 区分 | 要件 |
| --- | --- | --- |
| N-01 | 正確性 | 天体位置は天文計算ライブラリで算出する（歳差・章動を含む）。星座線・星表は公開の天文データを使用する |
| N-02 | 性能 | 通常のノート PC で滑らかに動作（空の描画は Canvas 2D、約 5,000 星＋低解像度の天の川・地面を毎フレーム描画） |
| N-03 | デザイン | 洗練された見た目。3D 感より、シーン間が自然につながる流れを優先 |
| N-04 | 互換性 | 最新の Chromium 系ブラウザ（Edge、Chrome）で確認。他ブラウザは未検証 |
| N-05 | レスポンシブ | スマートフォン幅でも HUD が崩れない |
| N-06 | 運用 | 静的ホスティング（GitHub Pages）で無料運用できる |
| N-07 | セキュリティ | 秘密情報を持たない。外部通信は Wikipedia・Google Fonts のみ |
| N-08 | 保守性 | TypeScript の strict 設定で型チェックが通ること |
| N-09 | ライセンス | 利用データ・ライブラリのライセンス（BSD-3、MIT、Wikipedia の各画像）に従い出典を表示する |

## 7. 制約・前提

- 技術：React、TypeScript、react-spring、GSAP など複数のアニメーション技術を使う（依頼者の指定）。
- 画面・解説文の言語は英語（依頼時の回答）。ドキュメントは日本語。
- 位置の指定は国→地域の手動選択（緯度・経度とタイムゾーンを得るため）。
- 星表は 6 等星まで（約 5,000 個）。暗い星・変光や固有運動の精密計算は対象外。

## 9. 課題・リスク

| 項目 | 内容 | 対応案 |
| --- | --- | --- |
| 解説の正確性 | 距離・年齢・面積などは概数を含み、一次資料で未校正 | 公開前に天文の有識者または公式資料（IAU、NASA 等）で校正 |
| Wikipedia 依存 | 写真・要約は実行時取得。API 仕様変更や画像の権利に依存 | フォールバックの星図を用意済み。ライセンス表示の整備 |
| 公開範囲 | GitHub Pages は private リポジトリでも公開される場合がある | 公開範囲・プランの確認（運用手順書 §3） |
| ブラウザ検証 | Edge のみで確認 | Chrome・Safari・スマートフォン実機での検証 |
| 3D 表現 | 依頼の参考（3D・粒子）に対し未対応 | 必要なら宇宙モードの背景に粒子を追加 |
